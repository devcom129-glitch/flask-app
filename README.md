# Simple Flask App

This is a basic Flask application that displays "Hello, World!" on the home page using an HTML template.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the app:
   ```
   python app.py
   ```

3. Run tests:
   ```
   pytest
   ```

## Files

- `app.py`: Main Flask application
- `templates/index.html`: HTML template for the home page
- `tests/test_app.py`: Simple test for the home route

## Troubleshooting

- If you get a port error, make sure port 5000 is not in use.
- Ensure Python and pip are installed.
